# Cálculo em Foco

Plataforma de aprendizagem ativa para Pré-cálculo e Cálculo I–IV voltada a estudantes de engenharia. O percurso combina diagnóstico, revisão de pré-requisitos, exemplos resolvidos e prática com feedback imediato.

## Desenvolvimento

```bash
npm install
npm run dev
```

Copie `.env.example` para `.env.local` e informe as credenciais públicas do projeto Supabase já usado pela aplicação.
